# Election Maps

A collection of precinct-level election maps created using ArcGIS Pro.

Maps are created using publicly available election returns and geographic boundary datasets.

## Maps

### 2026 Harris County Judge Election

Precinct-level visualization of the 2026 Harris County Judge election between Letitia Plummer (D) and Orlando Sanchez (R).

Geographic coverage: Harris County, Texas

Election data: Harris County Clerk's Office, Elections Department

Precinct boundaries: Harris County VPCTs_2026

Software: ArcGIS Pro

Visualization: Winning candidate's two-party vote share by precinct
